# ME Pro EQ — ME Audio

A 16-band equalizer for Windows 10/11 (64-bit VST3), aimed at FL Studio users. C++20, CMake, JUCE 9.

- Analog-matched bells and shelves, Butterworth cut filters 6 … 96 dB/oct, notch, band pass, tilt,
  all pass — 64-bit processing, 44.1 … 192 kHz, zero latency.
- Dynamic EQ on bell and shelf bands (internal or external sidechain), per-band Stereo / Left / Right /
  Mid / Side routing, band audition, mono check.
- Pre/post spectrum analyser, interactive graph showing the exact running responses.
- Presets (35 factory presets incl. Punjabi Production; user presets), A/B comparison, undo/redo,
  auto gain and level matching.

Status: milestone M2 complete. Linear-phase mode and analysis suggestions are planned (M3). **Not yet
tested inside FL Studio** — see [Documentation/ValidationReport.md](Documentation/ValidationReport.md).

## Building

Requirements: CMake ≥ 3.22, a C++20 compiler, Git. Tested toolchains: Visual Studio 2022 (MSVC, x64) and
GCC 13. JUCE 9.0.4 is fetched automatically and its commit is verified at configure time; to use a
local checkout pass `-DMEPROEQ_JUCE_DIR=<path>` (it must be the same commit).

Windows (from this folder):

```
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release --parallel
```

The plugin bundle is `build\MEProEQ_artefacts\Release\VST3\ME Pro EQ.vst3`.

Linux (development and CI; also builds a Linux VST3):

```
sudo apt-get install ninja-build libasound2-dev libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev \
  libxext-dev libxrender-dev libxcomposite-dev libxi-dev libfreetype-dev libfontconfig1-dev libgl-dev
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

Options: `MEPROEQ_BUILD_PLUGIN` (default ON; OFF builds only the JUCE-free DSP library and its tests),
`MEPROEQ_BUILD_TESTS`, `MEPROEQ_BUILD_BENCHMARKS`.

## Testing and validation

```
build/meproeq_dsp_tests    --report build/reports/dsp_test_report.md      # DSP accuracy, stability, automation
build/meproeq_plugin_tests --report build/reports/plugin_test_report.md   # real AudioProcessor + editor
build/meproeq_benchmark --seconds 10 --rate 48000 --block 256 --markdown build/reports/benchmark.md
```

(On Windows the executables are in `build\Release\`.) Every measured value is written into the reports.
The GitHub Actions workflow (`.github/workflows/me-pro-eq.yml`) additionally runs pluginval 1.0.4 at
strictness 10 and the Steinberg VST3 validator, and builds the installer only if all validation passed.

Installer (Windows, Inno Setup 6): see the header of `Installer/MEProEQ.iss`. Output:
`ME Pro EQ Setup.exe`.

Factory presets are generated by `Scripts/generate_factory_presets.py` into `Presets/Factory/` and
embedded into the plugin at build time.

## Plugin identity

Manufacturer code `MeAu`, plugin code `MePq`, bundle ID `com.meaudio.meproeq`. These determine the VST3
class IDs that projects use to find the plugin: never change them after release.
