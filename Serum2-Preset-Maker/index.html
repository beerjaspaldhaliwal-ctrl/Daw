    Using it with FL Studio
    1. Run the Windows installer. It makes a presets folder inside Serum 2's user presets (Documents\Xfer\Serum 2 Presets\Presets\User\Preset Maker), or Documents\Serum 2 Preset Maker\Presets if Serum 2 isn't installed.
    2. In FL Studio, drag that folder from File Explorer onto the Browser on the left. You only do this once.
    3. In the Browser's options menu, turn on Show unknown file types. Without it, FL Studio hides .SerumPreset files.
    4. Here, click Save to presets folder. The first time, pick the folder from step 1. Edge and Chrome remember it. A batch goes into a subfolder named after it.
    5. In FL Studio, drag the preset from the Browser onto Serum 2. To see it in Serum 2's own browser, rescan presets from Serum 2's menu.
    Claude AI
    • With Claude AI selected, Claude reads your description and picks every setting, so any words work ("spooky", "like a dubstep growl", "Daft Punk style lead"). It also explains its choices under "Why it sounds like this".
    • Online, it uses your Claude account. In the installed version it needs an Anthropic API key, which is billed to that account.
    • Packs are designed in one request. If Claude can't answer, the keyword reading is used instead and the page says why.
    Words the keyword reader understands
    • Sound type: bass, reese, 808 / sub bass, lead, supersaw / trance, pad, pluck, keys / piano, bell, stab / chord, arp
    • Tone: dark, warm, mellow, bright, airy, resonant / acid, wide / huge / lush, detuned, thin, chorus
    • Grit: dirty, saturated, distorted, aggressive, growl, clean, punchy / tight (compressor)
    • Layers: sub, noise / breathy, single oscillator, no sub
    • Shape: slow attack / swell, short / snappy, long / sustained, high, low, mono, poly
    • Exact values: attack 10ms, decay 300ms, sustain 50%, release 1.2s, cutoff 800hz, resonance 40, unison 7, octave -1
    • Name: put it in quotes or write called My Preset
    What gets set, and what doesn't yet
    • Each preset starts from Serum 2's own Init patch, so anything not in the editor stays at its Init value.
    • Oscillators use the factory Analog/Basic Shapes wavetable. The waveform positions are approximate.
    • No modulation yet (no LFO or envelope on the cutoff, no glide). Add these in Serum after loading.
    • Envelope decay, sustain and hold, and the sub octave, use parameter names that haven't been confirmed from a real preset yet. If they don't take effect, set them in Serum.
    • Inside claude.ai, downloads come as a .zip. The installed Windows version saves .SerumPreset files straight into your presets folder.
