What the text was read as
    Words it understands
    • Sound type: bass, reese, 808 / sub bass, lead, supersaw / trance, pad, pluck, keys / piano, bell, stab / chord, arp
    • Tone: dark, warm, mellow, bright, airy, resonant / acid, wide / huge / lush, detuned, thin, chorus
    • Grit: dirty, saturated, distorted, aggressive, growl, clean, punchy / tight (compressor)
    • Layers: sub, noise / breathy, single oscillator, no sub
    • Shape: slow attack / swell, short / snappy, long / sustained, high, low, mono, poly
    • Exact values: attack 10ms, decay 300ms, sustain 50%, release 1.2s, cutoff 800hz, resonance 40, unison 7, octave -1
    • Name: put it in quotes or write called My Preset
    What gets set, and what doesn't yet
    • Each preset starts from Serum 2's own Init patch, so any setting not listed above stays at its Init value.
    • Oscillators use the factory Analog/Basic Shapes wavetable. The waveform positions are approximate.
    • No modulation routings yet (no LFO or envelope on the cutoff). Add these in Serum after loading.
    • Envelope decay and sustain use parameter names that haven't been confirmed from a real preset yet. If they don't take effect, set them in Serum.
    • Inside claude.ai, the download comes as a .zip holding the preset. Open index.html from the repo on your computer to save the .SerumPreset file directly.
